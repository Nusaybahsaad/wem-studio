# Wem Studio - Next.js Application

مشروع تطبيق **Wem Studio** لتعلم اللغة الإنجليزية ومساحة التدوين اليومية المتكاملة، مبني بإطار **Next.js (App Router)** و **Tailwind CSS** وجاهز للنشر المباشر على **Vercel**.

## خطوات النشر على Vercel من الجوال أو الكمبيوتر:
1. فكي الضغط عن هذا الملف المضغوط (`wem-studio-nextjs.zip`).
2. ارفعي المجلد إلى مستودع جديد على حسابكِ في **GitHub** (أو عبر Vercel CLI).
3. ادخلي إلى موقع **Vercel.com** وسجلي الدخول بحساب GitHub.
4. اضغطي على **Add New Project** واختاري مستودع `wem-studio`.
5. اضغطي على **Deploy** مباشرة دون الحاجة لتغيير أي إعدادات!
